Create a quiz with Claude

You have your questions, your answers and your tracings: Claude turns them into a ready-to-play quiz in a few minutes. No coding needed.

  1. 1. PrepareYour questions and answers (Word, PDF, PowerPoint, text, screenshots…) and the image for each question.
  2. 2. Give them to ClaudeOpen claude.ai, paste the instructions below and attach your files.
  3. 3. CheckDrop the .json file you get into the checker at the bottom of this page: it flags errors and previews the quiz.
  4. 4. UploadPut the .json file and its image folder in quizzes/ on your server.

1. What to prepare

  • The questions, each with 2 to 6 answers and the correct one(s) clearly marked (bold, underlined, “Answer: B”…).
  • The images (tracings, ECGs, EGMs, diagrams): one per question, PNG or JPG, ideally 16:9. Name them in order (q01.png, q02.png…) or simply attach the PowerPoint: Claude extracts the images.
  • Optional: an explanation slide to show after the answer is revealed, the time per question (30 s by default), questions that count double.
  • The type of quiz:
    • one correct answer per question (like Kahoot): one tap on the phone answers;
    • one or more correct answers: players tick their answers then press Validate, with partial points.
Images must be readable on a screen shared in Zoom: at least 1200 px wide for a tracing, and no identifying patient data (name, date of birth, record number).

2. The instructions to give Claude

Copy this text into a new conversation on claude.ai, add your files, then send. Fill in the two lines in brackets at the end.

You are going to create a quiz for my live quiz app, from the questions, answers and images I am sending you.

DELIVERABLE
A .zip file containing:
- <id>.json: the quiz (format below);
- a folder <id>/ with the images: cover.jpg (or .png), q01.png, q02.png… and, if any, q01-explanation.png…
<id> = short name for the quiz: lowercase letters without accents, digits and hyphens (e.g. "conduction-disorders").

JSON FILE FORMAT (UTF-8)
{
  "id": "<id>",
  "title": "Title shown to players (short)",
  "description": "One or two sentences introducing the quiz.",
  "cover": "quizzes/<id>/cover.jpg",
  "time": 30,
  "scoring": "partial",
  "single": false,
  "questions": [
    {
      "q": "Question text",
      "img": "quizzes/<id>/q01.png",
      "time": 30,
      "points": 1,
      "choices": [
        { "t": "Full answer text", "s": "Short version (optional)", "ok": true },
        { "t": "Another answer", "ok": false }
      ],
      "explain": "quizzes/<id>/q01-explanation.png"
    }
  ]
}

RULES
1. Each question has 2 to 6 answers, in the order of my documents, and at least one answer with "ok": true.
2. Quiz type:
   - if every question has exactly ONE correct answer: "single": true and "scoring": "exact" (one tap on the phone = the answer);
   - otherwise: "single": false and "scoring": "partial" (partial points: each correct box ticked earns its share, each wrong box ticked takes one away).
3. "time" (seconds): 30 by default for the quiz; a question may have its own "time" (20 to 90). "points": 1 by default, 2 for a question that counts double. Do not write "time" or "points" in a question when they equal the default.
4. "q" and "t": keep my wording and my language word for word; only fix obvious spelling mistakes and typos, without changing the meaning.
5. "s" (short version): only if "t" is longer than 70 characters; about 60 characters at most, same meaning. It is shown on the shared screen; phones show the full text.
6. "img": one image per question if I provide one (otherwise leave "img" out). If my images are inside a PowerPoint, PDF or Word file, extract them. Trim useless white margins, maximum width 1600 px, PNG for tracings and diagrams, JPG for photos. Paths always start with "quizzes/<id>/".
7. "explain": only if I provide an explanation slide for a question; it is shown when the answer is revealed.
8. "cover": the cover image if I provide one, otherwise a copy of the first image of the quiz.
9. Do not add any question, answer or correct answer. If a correct answer is unclear in my documents, ask me before delivering.
10. Before delivering, check: valid JSON; every file referenced exists in the folder; same number of questions as in my documents. Then show a summary table: number, question, correct answer(s), image.

MY QUIZ
Title: [quiz title]
Notes: [e.g. one correct answer per question; 45 s per question; question 10 counts double]

Claude needs to be able to create files (on by default on claude.ai). Always read the summary table: you are the one who validates the correct answers.

3. Check the file

Drop the .json file created by Claude here. The check runs in your browser: nothing is sent anywhere.

4. Putting it online

Unzip it and upload <id>.json and the <id>/ image folder into quizzes/ on your server. The quiz then appears in the presenter’s list, next to the other quizzes. Players never see the correct answers before the reveal.
